## Rules from corrections

- Always render seat plan rows on a single line, regardless of how many columns an event has.
- Always show /agent-window when starting a new window.
- Keep the main chat window light to save its context: it only coordinates. Split any real work (design, building, fixing, audits, research, reviews) into a nested window (its own session), open it in split view, and have it report back to the main chat. The main chat checks each result (tests, diff) and merges or releases only when the user says so. Quick questions and one-line edits can stay in the main chat.
